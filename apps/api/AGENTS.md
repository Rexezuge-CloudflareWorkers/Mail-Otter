# Mail-Otter — API Worker

Scope: `apps/api/**`. Parent index: `../../AGENTS.md`.

- `src/index.ts` — exports `fetch`/`scheduled`/`queue` via `MailOtterWorker` + `EmailEventsDispatcherWorker`; re-exports `CronTasksWorker`, `EmailProcessingWorkflow`, `OAuth2TokenRefreshWorker` for DO/Workflow bindings.
- `src/types.d.ts` — `type Env = CloudflareEnv` global.
- `src/workers/MailOtterWorker.ts` — Hono + Chanfana routes, D1 sessions (`x-d1-bookmark` header round-trip in `onRequest`), cron → `CronTasksWorker` DO.
- `src/endpoints/` — file-routed endpoint classes (`api/`, `user/`, `IBaseRoute.ts`, `IUserRoute.ts`).
- `src/middleware/` — `index.ts`, `MiddlewareHandlers.ts` incl. Cloudflare Access auth.
- `src/generated/spa-shell.ts` — generated by web build; do not edit.

## Auth

- `/user/*` — Cloudflare Access. `EmailValidationUtil.getAuthenticatedUserEmail` reads the `cf-access-jwt-assertion` header, verifies via `jose` against `{TEAM_DOMAIN}/cdn-cgi/access/certs` with audience `POLICY_AUD`, extracts `payload.email`.
- `DEV_AUTH_EMAIL` (no default, local-only) bypasses Access and returns directly.
- `/docs`, `/openapi.json` — Chanfana generated (`fromHono`).
- `/api/oauth2/callback/:applicationId` — public; one-time state + PKCE.
- `/api/actions/:actionId*` — public (email client links); encrypted + signed tokens.
- `/api/webhooks/*` — public; Gmail tokenized URL, Outlook Graph `clientState`, Fastmail shared secret.
